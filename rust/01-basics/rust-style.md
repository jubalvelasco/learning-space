# **[Rust Lang](../Rustlang.md)**

## **Naming Conventions**

| | |
| --- | --- |
| functions | snake case |
| variables | snake case |
| modules | snake case |
| types (structs, enums, traits) | upper camel case (PascalCase) |
| enum variants | upper camel case (PascalCase) |
| constants & statics | screaming snake case (`MAX_POINTS`) |
